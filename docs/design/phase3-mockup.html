rock-esp32 · Фаза 3 — редизайн GUI под палитру rockcast

Мокап всех экранов прошивки в реальной геометрии матрицы 800×480 (ST7701, софт-поворот). Источник палитры и компонентного языка — десктопный rockcast (src/app/theme.rs, ui/controls.rs, ui/stations/*). Размеры в пикселях 1:1 к будущему LVGL-лейауту.

Стадия 1 — мокап. Файл является проектным артефактом: до явного утверждения код прошивки не меняется. Замечания правятся только в этом HTML.

Ключевые решения · что откуда взято

Перенесено с десктопа 1:1

  • Палитра theme.rs: BG #15110E, PANEL #201914, PANEL_2 #2A211B, BORDER #3B2C23, BORDER_SUBTLE #2D211A, FG #F3EEE9, ACCENT #E56020, MUTED #9E8D82, GREEN #3DDC84
  • Панель-рецепт: fill PANEL · radius 10 · рамка 1px BORDER_SUBTLE · паддинг 12
  • Монограммы станций: 8 цветов + выбор по хэшу имени (порт station_color), инициалы 1–2 символа, текст #FAEEE4; в деке — кольцо ACCENT
  • Строка трека: ACCENT при воспроизведении, MUTED в покое + зелёная live-точка
  • Круглый транспорт Play: ACCENT-заливка в игре / PANEL_2 + кольцо ACCENT в покое
  • Спектр: бары r2 gap 3 прямо на панели (без коробки), ACCENT/BAR_DIM, белые 2px peak-тики
  • Футер дека: статусная точка + мелкий MUTED-текст + micro-подпись «RockServer Cloud»
  • Строка поиска: PANEL · 1px BORDER · r8 · иконка лупы · ✕ очистки · кнопка микрофона
  • Список: зебра #201814, текущая строка — ACCENT, вторичный текст на ней #3A281C
  • Чипы жанров: прозрачные с рамкой BORDER, активный — ACCENT

Адаптировано под тач 800×480

  • Транспорт-бар 768×64 сохраняет весь набор кнопок (Каталог · Поиск · Play/Pause · Stop · Vol− · Vol+ · Cast) — обработчики фаз 1–2 не трогаем, меняется только стиль: нав-пилюли 48px, круглая Play 64px, вторичные круги 56px
  • Слайдер громкости десктопа → существующие кнопки Vol−/+ с процентами hack_16 (как сейчас)
  • Монограмма дека 96×96 (у десктопа 48) — станция главный объект экрана; имя inter_24 marquee
  • Спектр 296×168 справа в деке (был 256×80 в коробке PANEL_2 под арт-блоком 80×80)
  • Строки списка 56px: монограмма 40×40 вместо серого бокса-инициала; вся строка — тач-зона (как сейчас)
  • Клавиши поиска ≥48px, кнопки оверлеев и каст-меню 44–48px (сейчас 32–42)
  • Чипы жанров 48px-пилюли (тач-таргет ≥48 по правилу токенов)
  • Hover/двойной клик десктопа не переносятся — отклик только по нажатию

Новое на девайсе

  • Кнопка микрофона в строке поиска: статичный янтарный #E67E22, визуальный задел фазы 4 — выводится неактивной (без обработчика, нажатие игнорирует молча)
  • Статусная точка в тикере слева: зелёная / янтарная / серая / красная — только стиль, тексты тикера не меняются
  • Бейдж «СЕЙЧАС ИГРАЕТ» сохраняется (существующий виджет); при касте показывает имя ресивера (как сейчас)
  • Счётчик «N станций» в шапке каталога — статичная подпись, данных не требует

Поведенческие последствия · что меняется кроме стилей — прочитать до утверждения

  1. Арт-блок 80×80 удаляется (плейсхолдер с иконкой ▶ справа). Вместо него — монограмма 96×96 в составе дека, цвет детерминирован хэшем имени станции. Обработчика у арта не было — меняются только виджеты.
  2. Спектр переезжает и меняет отрисовку: коробка PANEL_2 256×80 → бары прямо на панели дека 296×168 + белые peak-тики. Таймер 34 мс должен дополнительно вести пик-значения с медленным спадом — это новая мини-логика внутри gui_now_playing_spectrum_update() (не событийная, FPS проверить на девайсе).
  3. Набор кнопок транспорт-бара сохранён полностью (Каталог, Поиск, Play/Pause, Stop, Vol−, Vol+, Cast, % громкости) — обработчики и события очереди не меняются; меняются только стили (круглые кнопки ≥48).
  4. Поиск: текстовая кнопка «Очистить» заменяется иконкой ✕ внутри строки поиска (колбэк тот же); добавляется неактивная кнопка микрофона — без обработчика, нажатие ничего не делает и не логирует (задел фазы 4).
  5. Клавиатура занимает 236px вместо 220px (клавиши ≥48px): при вводе контент выше не меняется, результаты всё равно скрыты — поведения не меняет.
  6. Browse-ряд: серый бокс-инициал 40×40 → монограмма station_color; текущая станция подсвечивается заливкой ACCENT всей строки (сейчас — только ▶ справа); клик по строке — тот же обработчик, мини-эквалайзер в текущей строке — чисто индикативный виджет без события.
  7. Каст-меню: строки 42→52px, «Обновить»/✕ доведены до 44–48px; активный приёмник — строка ACCENT вместо текстового бейджа; локальный выход — зелёная точка вместо [Активен] ACCENT. Обработчики те же.
  8. State-оверлей: главная кнопка «Повторить» становится ACCENT (сейчас ACCENT у «Назад»); порядок кнопок и колбэки не меняются.
  9. Тикер: добавляется статусная точка слева (green/amber/muted/red по состоянию плеера) — только стиль, тексты и логика тикера не меняются.
  10. Футер дека: новые статические подписи (статус + «RockServer Cloud») — только отображение; имя сервера берём из существующей конфигурации, при отсутствии подпись «RockServer».
