# Дизайн-токены RockCast для нативного GUI устройства (ESP32-P4 / LVGL v9)

Спецификация визуального языка прошивки после фазы 3 (редизайн под палитру
десктопного rockcast, `c:\repos\rockcast\src\app\theme.rs`). Эталон дизайна —
утверждённый мокап `docs/design/phase3-mockup.html` (геометрия всех экранов
1:1); эта документа — краткая выжимка токенов и правил для кода.

Экран: ST7701 480×800, софт-поворот в **800×480 landscape**, тач GT911, ~217 PPI,
пальцевый ввод без ховера. Реализация токенов: `components/rock_gui/include/rock_ui_tokens.h`.

---

## 1. Палитра

Тёплая аналоговая гамма винтажного радио: кофейно-древесные фоны, светлый
кремовый текст, терракотово-оранжевый акцент.

### 1.1. Базовые токены

| Токен C | Роль | Hex | Где используется |
| :--- | :--- | :--- | :--- |

Тёмный текст на ACCENT-заливке — `ROCK_COLOR_BG` (`#15110E`).

### 1.2. Монограммы станций

Цвет монограммы детерминирован именем станции (порт `station_color()` из
`theme.rs`, реализация `rock_ui_station_color()` в `rock_gui_widgets.c`):

```
h = 0; for byte of utf8(name): h = h*31 + byte (u32 wrap); palette[h % 8]
```

| # | Hex | # | Hex |
| :--- | :--- | :--- | :--- |
| 0 | `#382216` | 4 | `#3D2C1D` |
| 1 | `#481A16` | 5 | `#441B17` |
| 2 | `#302824` | 6 | `#282523` |
| 3 | `#522814` | 7 | `#5A2E15` |

Текст монограммы `ROCK_COLOR_MONO_TEXT`, инициалы — первые 1–2
буквенно-цифровых символа имени (ASCII + кириллица), uppercase. В деке
монограмма 96×96 r8 с кольцом 2px ACCENT; в строках списка — 40×40 r8 без кольца.

### 1.3. Состояния

| Состояние | Индикация |
| :--- | :--- |
| Playing | точка тикера `GREEN`, live-точка у трека, трек `ACCENT`, спектр `ACCENT`, футер «Прямой эфир» |
| Buffering | точка тикера `WARN`, спиннер `ACCENT` |
| Paused/Stopped/Idle | точка тикера `MUTED`, трек `MUTED`, спектр почти плоский `BAR_DIM` |
| Error | точка тикера `ERROR`, error-оверлей (иконка `ERROR` в круге `PANEL_2`) |
| Каст активен | строка приёмника залита `ACCENT`; кнопка Cast в транспорте — `ACCENT` |

(«ROCKSERVER CLOUD» и т.п.) — `inter_14`.

| Шрифт | Роли |

| `hack_16` | часы в шапке, проценты громкости |

## 3. Геометрия и рецепты

### 3.1. Радиусы и отступы

| Токен | Значение | Примечание |
| :--- | :--- | :--- |
| `ROCK_RADIUS_PANEL` | 10 | панели (было 8) |
| `ROCK_RADIUS_WIDGET` | 8 | виджеты, клавиши, монограммы (было 6) |
| `ROCK_RADIUS_BUTTON` | 8 | кнопки, строки списка (было 4) |
| `ROCK_RADIUS_BAR` | 2 | бары спектра |

**Панель-рецепт** (дек, транспорт, клавиатура, карточки оверлеев/каста):
fill `PANEL` · radius 10 · рамка 1px `BORDER_SUBTLE` · внутренний отступ 12.

### 3.2. Тач-таргеты и структурные высоты

| Правило | Значение |
| :--- | :--- |
| `ROCK_TOUCH_TARGET_MIN` | 48 px — все интерактивные элементы |
| `ROCK_LIST_ROW_HEIGHT` | 56 px (5 видимых строк в Browse, 4 в Search, зазор 4) |
| `ROCK_HEADER_HEIGHT` / `ROCK_TRANSPORT_HEIGHT` / `ROCK_STATUS_BAR_HEIGHT` | 40 / 64 / 36 px |

Транспорт: пилюли 48px (r24), Play — круг 64 (r32), Stop/Vol — круги 56 (r28),
кластер центрирован, зазор 16. Клавиатура 768×236, клавиши ≥48 (4 ряда, зазор 6).
Кнопки оверлеев 176×48; «Обновить»/✕ каст-меню 44px.

### 3.3. Ключевые блоки

- **Дек Now Playing** 768×300 @(16,52 от верха экрана): монограмма 96×96,
  инфо-колонка 288, спектр 296×168 справа без подложки (16 баров, ширина 15,
  шаг 18, r2, зазор 3; белые peak-тики 2px с медленным спадом; в покое —
  плоские ~12px `BAR_DIM`), разделитель 1px `BORDER`, футер 30px
  (точка + статус + «ROCKSERVER CLOUD»).
- **Строка списка** 768×56: монограмма 40×40 · имя `inter_18` · теги `inter_14`
  MUTED · метапоток 92px справа · ▶ ACCENT / мини-эквалайзер (4 белых бара) у
  играющей. Играющая строка: заливка ACCENT, имя тёмным (`BG`), вторичный
  `SEL_TEXT_SEC`.
- **Строка поиска** h44 (`PANEL`, 1px `BORDER`, r8): лупа MUTED → текст
  `inter_18` → ✕ 36px → микрофон 36px (`MIC_AMBER` @45%, неактивен — задел
  фазы 4, нажатие — молчаливый no-op).
- **Чипы жанров**: пилюли 48px, прозрачный фон + рамка `BORDER`, текст MUTED.
- **Клавиатура**: клавиши `PANEL_2` r8 + `BORDER_SUBTLE`, `inter_18`; OK — `ACCENT`
  (ctrl-флаг `CHECKED` у клавиши → стиль `LV_PART_ITEMS | LV_STATE_CHECKED`;
  в этой версии LVGL биты `CUSTOM_*` состояния не дают). Служебные клавиши
  (RU/EN/123, ⌫, стрелки, пробел) стилистически едины с буквенными.
- **Каст-меню**: карточка 600px r10; шапка 44 (заголовок + «Обновить» + ✕);
  строки 52 (ибокс 40×40, имя, бейдж-точка + статус); локальный выход —
  зелёная точка «Активен», активный приёмник — ACCENT-строка.
- **State-оверлеи**: карточка 520×260 (ошибка — 520×280), спиннер 56px
  (дуга ACCENT 4px / трек PANEL_2), иконка в круге 56px; кнопки: главная
  «Повторить» — ACCENT, «Назад» — PANEL_2 + BORDER.
- **Тикер**: статусная точка 9px (green/amber/red/muted) + текст MUTED.

## 4. Правила адаптации с десктопа

1. Ховер и двойной клик десктопа не переносятся — отклик только по нажатию.
2. Слайдер громкости десктопа → кнопки Vol−/+ с процентами `hack_16`.
3. Все тач-таргеты ≥48px; тексты крупнее десктопа (имена 18, станция 24).
4. Наборы кнопок, обработчики и очередь событий не зависят от стилей: фаза 3
   меняет только стили/раскладку/создание виджетов.
5. Микрофон на девайсе — статичный янтарь `#E67E22` (у десктопа динамика нет);
   голосовой ввод — фаза 4.

Обновление `docs/rockcast-device-preview.html` в фазу 3 не входит.
